# Kunal Urkude — Portfolio

Personal portfolio: EV projects, robotics teaching, video editing, design work, web apps and skills.
Plain HTML, CSS and JavaScript. No build step.

**Live:** https://kunalurkude.github.io/Portfolio/

## Editing content

Almost everything is in **`js/data.js`**: contact links, videos (YouTube IDs), logos, posters, thumbnails, apps, websites, robotics links and skills. Edit it on GitHub and commit; the site updates in about a minute.

The EV case study, teaching section and hero text are in `index.html`. Images are in `assets/`.

## Hosting

GitHub Pages: Settings → Pages → Deploy from a branch → `main` / root. Works on Vercel and Netlify too (no build command, publish the root folder).
